P-Collector 利用規約

最終更新日：2026年8月2日

本規約は、モバイルアプリ「P-Collector」（以下「本アプリ」）の利用条件を定めます。本アプリを利用した時点で、本規約に同意したものとみなします。詳細版は こちら をご覧ください。

1. 利用許諾

開発者は、利用者に対し、本規約の範囲内で本アプリを非独占的に利用する権限を付与します。

2. 本アプリの概要・データソース

本アプリは、コレクション管理、セット進捗（コンプリート）、コレクタースコアランキング、カード掲示板、市場参考価格の表示などを提供します。売買の仲介は行いません。価格・スコアは参考情報です。

英語版カード情報（メタデータおよび画像 URL）は、オープンデータセット TCGdex（tcgdex/cards-database、MIT License）を ビルド時に取り込み、アプリ内にバンドルされた検索用データベースとして提供します。アプリ実行時に api.tcgdex.net へリクエストを送信することはありません。日本語版のカード名等のメタデータも、アプリ内にバンドルされた検索用データベース（事実情報および TCGdex 由来のデータ）から取得します。新弾追加等の更新は、運営者が管理する公開 GitHub リポジトリ posmap-japan/p-collector-card-db（MIT License）に配置し、無料の公開 CDN である jsDelivr（cdn.jsdelivr.net）経由でアプリへ差分配信されます（メタデータのみ）。新弾反映後はセット進捗およびコレクタースコアの算出対象にも含まれます。カード画像は TCGdex 公開 CDN（assets.tcgdex.net、MIT License）、TCGplayer の公開画像 CDN（tcgplayer-cdn.tcgplayer.com）、および Pokémon TCG API（images.pokemontcg.io、フォールバック用途）にホストされた URL を通じて参照表示しており、運営者は画像を再配布していません。TCGplayer CDN の画像 URL インデックスは、運営者が PokemonPriceTracker API を ビルド時のみ（有料プランの利用規約に従って）利用し取得したもので、アプリ実行時に同 API を呼び出すことはありません。市場参考価格およびバンドルデータベースに未収録の英語カード検索には、Pokémon TCG API（api.pokemontcg.io）と楽天市場 API（日本語設定時）を実行時に補助的に利用します。外部マーケットへの遷移 URL にアフィリエイト用パラメータが付与される場合があります。本アプリは、株式会社ポケモンが運営する pokemon-card.com に対する自動化アクセスや、同サイトにホストされた画像へのホットリンクを行いません。

3. 公開ランキング・掲示板

ログイン時、表示名・写真・コレクタースコア等が他のユーザーに表示されることがあります。掲示板への投稿は公開されます。誹謗中傷・スパム・権利侵害等の投稿は禁止し、運営者は違反コンテンツを削除できます。スコア配点は予告なく変更されることがあります。

4. 非公式表示・知的財産権

「ポケモン」「Pokémon」は株式会社ポケモン等の商標・登録商標です。ポケモンカードゲームに関する著作権・商標等の権利は同社および関連権利者に帰属し、本アプリはこれらの企業に承認・提携されたものではありません。本アプリは非公式のファンメイドツールです。

5. 削除依頼窓口

権利者または正当な権利主張者からの削除・是正要請を受けた場合は、速やかに対応します。posmap.japan@gmail.com までご連絡ください。

6. 禁止事項

法令違反、他者の権利侵害、本アプリや関連サービスの不正利用、過度な負荷を与える行為、掲示板での迷惑行為、不正なスコア操作等を禁止します。

7. 免責

本アプリは現状有姿で提供されます。表示されるカード情報・価格・スコア等は参考であり、正確性・完全性を保証しません。本アプリは外部 API および公開 CDN（TCGdex、TCGplayer 画像 CDN、Pokémon TCG API、楽天市場 API、jsDelivr 等）に依存しており、これらのサービスの停止・変更により一部機能が利用できなくなる場合があります。利用により生じた損害について、開発者に故意または重過失がある場合を除き責任を負いません。

8. 広告・アフィリエイト

現時点ではアプリ内課金および第三者広告 SDK による広告表示はありません。外部サイトへのアフィリエイトリンクを含む場合があります。

9. 規約の変更

開発者は必要に応じて本規約を変更できます。重要な変更がある場合は、アプリ内または本サイトでの表示等により周知するよう努めます。

10. 準拠法

本規約は日本法を準拠法とします。
