P-Collector 利用規約

最終更新日：2026年8月2日

本利用規約（以下「本規約」）は、P-Collector（以下「本アプリ」）の利用条件を定めるものです。本アプリをインストール、登録、または利用した時点で、本規約に同意したものとみなします。同意いただけない場合は、本アプリの利用をお控えください。

第1条（定義）

  1. 「運営者」とは、本アプリの開発・運営を行う個人を指します。
  2. 「ユーザー」とは、本アプリをインストールまたは利用するすべての方を指します。
  3. 「コレクションデータ」とは、ユーザーが本アプリ上で登録・管理するカード情報（カード ID、所持数、メモ等）を指します。
  4. 「本サービス」とは、本アプリが提供するすべての機能を指します。
  5. 「公開プロフィール」とは、コレクタースコアランキング等のために他のユーザーに表示される表示名・写真・スコア等の情報を指します。

第2条（本アプリの概要）

本アプリは、ユーザーが個人的に所有するポケモンカードのコレクション情報を記録・管理し、セット進捗（コンプリート）の確認、コレクタースコアによるランキング、カード掲示板、外部 API およびバンドルデータを通じた市場価格の参考情報表示などを提供するツールです。

  • 本アプリは、カードの売買を仲介するものではありません。
  • 本アプリに表示される市場価格や買取相場、資産評価額、コレクタースコアはあくまで参考情報であり、実際の取引価格や他者との優劣を保証するものではありません。
  • 英語版カード情報（カード名・セット名・番号・レア度等のメタデータ、および画像 URL）は、オープンデータセット TCGdex（tcgdex/cards-database、MIT License）を ビルド時に取り込み、アプリ内にバンドルされた検索用データベースとして提供しています。実行時に TCGdex の API（api.tcgdex.net）へリクエストを送信することはありません。
  • カード DB の差分配信（ホットアップデート）：上記の英語版・日本語版検索用データベースは、新弾追加等の更新を行った際、運営者が管理する公開 GitHub リポジトリ posmap-japan/p-collector-card-db（MIT License）に配置し、無料の公開 CDN である jsDelivr（cdn.jsdelivr.net）経由でアプリへ配信します。アプリは小さな manifest ファイルを定期的に取得し、自身が保持するバージョンより新しい場合のみ JSON 本体をダウンロードします。差分配信される内容は前項のメタデータのみで、画像・イラスト・ゲームテキスト等の著作物は含みません。新弾がデータベースに反映されると、セット進捗一覧およびコレクタースコアの算出対象にも自動的に含まれます。
  • 日本語版カード情報（カード名・セット名・番号等のメタデータ）は、アプリ内にバンドルされた検索用データベースから取得します。本データベースは、オンラインで公開されている書誌的情報（事実情報）および TCGdex 等のオープンデータセットに基づいて運営者が編纂したものであり、画像・イラスト・ゲームテキスト等の著作物性の高いコンテンツは含みません。
  • カード画像は、外部 CDN にホストされた URL を通じて参照表示しています。本アプリは画像ファイルを再配布していません。利用する外部 CDN は以下のとおりです。
    • TCGdex 公開アセット CDN（assets.tcgdex.net、MIT License）— 英語・日本語等の主要カード画像
    • TCGplayer 公開画像 CDN（tcgplayer-cdn.tcgplayer.com）— TCGdex に画像が存在しない日本語カード画像の一部。画像 URL のインデックスは、運営者が PokemonPriceTracker API（pokemonpricetracker.com、有料プランの利用規約に従って取得）を ビルド時に 利用して取得し、アプリ配布物には当該 URL のみを埋め込んでいます。PokemonPriceTracker API へのリクエストはアプリ実行時には発生しません。
    • Pokémon TCG API（images.pokemontcg.io）— バンドルデータベースに未収録の英語カードを実行時に取得した場合の画像（フォールバック用途）
  • 市場価格の参考情報および バンドルデータベースに未収録の英語カード検索 には、Pokémon TCG API（api.pokemontcg.io）を実行時に補助的に利用します（送信される情報はユーザーが入力した検索文字列等に限られ、個人情報は送信されません）。
  • 日本語設定時の市場参考価格は楽天市場 API（Rakuten Ichiba API）から取得しています。カード詳細から楽天市場・TCGPlayer・Cardmarket・eBay・Amazon 等の外部サイトへ遷移する場合があり、運営者が設定したアフィリエイト用パラメータが URL に付与されることがあります。
  • 本アプリは、株式会社ポケモンが運営する pokemon-card.com 等の公式ウェブサイトに対して、自動化されたクロール・スクレイピング等の行為を行いません。また、同サイトにホストされた画像への直接リンク（ホットリンク）も行いません。
