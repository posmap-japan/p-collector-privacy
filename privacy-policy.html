P-Collector プライバシーポリシー

最終更新日：2026年8月2日

本ポリシーは、モバイルアプリ「P-Collector」（以下「本アプリ」）における利用者情報の取り扱いについて定めます。詳細は Markdown 版（privacy-policy.md）と同一の趣旨です。

1. 収集する情報

1-1. アカウント情報
Google サインインまたは Apple サインインを利用する場合、認証プロバイダ経由でメールアドレス、表示名、プロフィール画像URL、一意の識別子（UID）などが取得されることがあります。アプリ内で設定した表示名・プロフィール写真（Firebase Storage に保存される場合あり）も対象です。パスワードは運営者が保持せず、Firebase Authentication 等の仕組みに委ねます。

1-2. コレクションデータ
利用者が登録したカードID、所持枚数、レア度別メモ・価格、登録日などのデータが、クラウド同期等のために保存される場合があります。また、日次で記録される価格履歴データ（個別カードの市場価格スナップショット、ポートフォリオ総額・レア度別評価額の推移）も保存されます。

1-3. 公開プロフィール・ランキング
ログイン時、表示名・プロフィール写真・コレクタースコア（内訳を含む場合あり）・所持数の集計値などが Cloud Firestore に保存され、他のユーザー向けランキングに表示されることがあります。個別カード一覧はランキングでは公開されません。

1-4. 掲示板
カードごとの掲示板に投稿した本文、投稿者の表示名・UID・プロフィール写真、投稿日時が保存・公開されます。

2. 利用目的

本アプリの提供・改善、同期機能の提供、市場価格・価格推移の表示、セット進捗およびコレクタースコアランキングの提供、掲示板の運営、お問い合わせ対応、法令に基づく対応のために利用します。

3. 第三者サービス

以下の外部サービスを利用する場合があります。各サービスのプライバシーポリシーに従います。

  • Google Firebase（Authentication, Cloud Firestore, Cloud Storage, Analytics）— 認証・データ保管・プロフィール画像・分析
  • Google Sign-In / Apple Sign In — ログイン認証
  • jsDelivr（cdn.jsdelivr.net）— 運営者が管理する公開 GitHub リポジトリ posmap-japan/p-collector-card-db にホストされた、カードのメタデータと manifest ファイルを差分配信するための無料公開 CDN。アプリは小さな manifest を取得し、より新しいバージョンが存在する場合のみ JSON 本体をダウンロードします。送信されるのは HTTP リクエスト（URL／User-Agent／IP アドレス）のみで、コレクションデータや個人情報は送信されません。jsDelivr プライバシーポリシー
  • TCGdex（assets.tcgdex.net）— 英語・日本語等のカード画像表示用公開 CDN を参照（ユーザーの個人情報は送信されません）。英語カードのメタデータは tcgdex/cards-database（MIT License）を ビルド時のみ 取り込んでアプリに同梱しており、アプリ実行時に api.tcgdex.net へリクエストが送信されることはありません。
  • TCGplayer 公開画像 CDN（tcgplayer-cdn.tcgplayer.com）— TCGdex に画像が存在しない日本語カード画像の表示（画像ファイルの参照のみ）。TCGplayer プライバシーポリシー
  • Pokémon TCG API（api.pokemontcg.io / images.pokemontcg.io）— 市場価格（参考情報）の取得、およびバンドルデータベースに未収録の英語カードの検索・画像参照（フォールバック用途）。ユーザーが入力した検索文字列等が送信されますが、個人情報は送信されません。
  • 楽天市場 API（Rakuten Ichiba API） — 日本語設定時の市場参考価格の取得および商品リンク表示（カード名を検索キーワードとして送信。ユーザーの個人情報は送信されません）
  • 外部マーケット（TCGPlayer / Cardmarket / eBay / Amazon 等）— 遷移 URL にアフィリエイト用パラメータが付与される場合があります。取扱いは各サービスのポリシーに従います。

日本語カード画像のうち、TCGdex に未収録のカードについては、画像 URL のインデックスを運営者が ビルド時のみ pokemonpricetracker.com（PokemonPriceTracker）の有料プランを利用して取得しています。当該 API の API キーはアプリ配布物には含まれず、アプリ実行時に PokemonPriceTracker へリクエストが送信されることはありません。アプリ実行時は、取得済みの URL を参照して TCGplayer の公開 CDN から画像を読み込むのみです。

本アプリは、株式会社ポケモンが運営する pokemon-card.com に対して、自動化されたクロール・スクレイピング等の行為を行いません。また、同サイトにホストされた画像への直接リンク（ホットリンク）も行いません。

4. 権利者からの削除依頼

カード画像・情報等について、権利者または正当な権利主張者からの削除・是正要請があった場合、運営者は速やかに対応します。posmap.japan@gmail.com までご連絡ください。

5. データの保存と削除

ローカルデータは端末のアプリデータ削除またはアンインストールにより消去されます。アプリ内の「アカウントを削除」機能により、Firebase Authentication のアカウント情報およびコレクション同期データが削除されます。公開ランキング用プロフィール、掲示板への投稿、プロフィール画像については、posmap.japan@gmail.com へのお問い合わせにより削除を請求でき、運営者は合理的な期間内に対応します。

6. お問い合わせ

本ポリシーに関するお問い合わせは、posmap.japan@gmail.com までご連絡ください。
